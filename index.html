Web app

Install from the browser

Open your own gateway at 127.0.0.1:18790/panel.html and choose Install app. Same panel, no download, on any phone or desktop that can reach your gateway.

Terminal

npm

One package gives you the gateway, the CLI and the control panel on Windows, macOS and Linux.

$ npm install -g @noirarh/noira

Get started

npm install -g @noirarh/noira
noira onboard        # pick Claude, an OpenAI-compatible model or Ollama
noira start          # the gateway, in the background
noira                # chat with it · noira panel opens the control panel

Needs Node 22 or newer, plus a Claude or OpenAI-compatible key, or a local model with Ollama. Keys, memory and files stay in ~/.noira. Full guide in the docs.
